# MATE4: Executive Finance

"Crie o layout de um dashboard SaaS premium de controle financeiro e contábil chamado 'MATE4'.
ESTILO VISUAL: O tema deve ser 'Dark Mode' sofisticado, inspirado em altos executivos e finanças.
CORES (Use EXATAMENTE estes códigos Hex):

Background principal: #1A1D21 (Grafite escuro)

Background de cards e barras laterais: #25282D (Grafite mais claro)

Cor primária/acentos: #4A5D23 (Verde Musgo)

Cor de destaque premium (use APENAS para indicar lucro, ganhos ou botões de ação principal): #CD7F32 (Bronze)

Texto principal: #F2F0EB (Claro)
TIPOGRAFIA: Use a fonte 'Manrope' importada do Google Fonts para todo o sistema. Deixe os números das métricas financeiras um pouco maiores e em negrito (Bold).
BARRA LATERAL: No canto superior esquerdo, coloque o texto 'MATE4' em Verde Musgo com um ícone minimalista de uma Rainha de Xadrez ao lado. Abaixo, os menus: Dashboard, Fluxo de Caixa, Notas Fiscais, Créditos IBS/CBS, Compliance.
DASHBOARD: Crie 4 cards na parte superior. Três deles com borda sutil na cor Verde Musgo, e O CARD DE 'LUCRO LÍQUIDO' deve ter uma borda na cor Bronze para destacar. Abaixo, um gráfico de linhas usando a cor Verde Musgo."
